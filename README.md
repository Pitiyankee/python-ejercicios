# Prácticas de Python

Ejercicios de Python 3 sobre archivos de texto, funciones y bucles.

## Ejercicio 5: archivos, funciones y bucles

Carpeta `ejercicio-5-archivos-funciones-bucles/`. Cada tarea tiene un script que genera un archivo de texto y otro que lo muestra:

| Tarea | Genera | Muestra |
|---|---|---|
| 1. Alumnos | `01_crear_alumnos.py` | `01_mostrar_alumnos.py` |
| 2. Notas | `02_registrar_notas.py` | `02_mostrar_notas.py` |
| 3. Resumen de notas | `03_generar_resumen.py` | `03_mostrar_resumen.py` |
| 4. Votación | `04_registrar_votos.py` | `04_mostrar_resultados.py` |
| 5. Invitaciones | `05_generar_invitaciones.py` | `05_mostrar_invitaciones.py` |
| 6. Menú de simulaciones | `06_menu_simulaciones.py` | |

## Cómo ejecutarlo

```bash
cd ejercicio-5-archivos-funciones-bucles
python 01_crear_alumnos.py
python 01_mostrar_alumnos.py
```
