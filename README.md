# Prácticas de Python

Ejercicios de Python 3 sobre bucles, selección, el módulo `math`, diccionarios, archivos de texto y funciones. Cada carpeta es independiente y se ejecuta con `python <archivo>.py`.

| Carpeta | Qué trabaja |
|---|---|
| `ejercicio-1-bucles-while-for` | Bucles `while` y `for`: cuenta regresiva, sumas, tablas de multiplicar, pares, vocales y números primos |
| `ejercicio-2-seleccion-bucles` | Condicionales, operador ternario, menús, contraseñas, `enumerate` y búsquedas |
| `ejercicio-3-modulo-math` | Cálculos con el módulo `math`: baldosas, autobuses, cajas, bacterias, radianes, rampas y exponentes |
| `ejercicio-4-simulador-ufc` | Simulador de matchmaking y registro de peleadores con diccionarios y funciones |
| `ejercicio-5-archivos-funciones-bucles` | Lectura y escritura de archivos de texto, funciones, bucles y un menú de simulaciones |

## Cómo ejecutarlo

```bash
cd ejercicio-1-bucles-while-for
python ejercicio1_cuenta_regresiva.py
```

En el ejercicio 5, cada tarea tiene un script que genera su archivo de texto y otro que lo muestra (`01_crear_alumnos.py` y `01_mostrar_alumnos.py`, y así hasta el 05). El `06_menu_simulaciones.py` reúne las simulaciones en un menú.
